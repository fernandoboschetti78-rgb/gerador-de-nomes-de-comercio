# gerador-de-nomes-de-comercio

projeto de estudo de html

para rodar, certifique-se:
- ter flask instalado (se não tiver instale com pip install flask)
- botar todos os arquivos do repositorio na mesma pasta (exceto o readme.md)
- apos isso, com o terminal nessa pasta rode: `python app.py` ou `python3 app.py`, dependendo de qual você tiver instalado
- depois que o servidor for inicializado, no seu navegador abra a url http://localhost:5000
